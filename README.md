# Hompage Navbar Web Template 5

A bold and responsive **brutalist homepage and navbar web template** built with HTML5, CSS3, and Vanilla JavaScript.

This template uses a distinctive Brutalist design language with oversized typography, strong borders, sharp layouts, direct visual hierarchy, and unconventional interface elements.

It is part of the **Hompage Navbar Web Template** series, where every template features a completely different design identity, layout, typography style, and color palette.

## Features

* Brutalist homepage design
* Responsive navbar
* Desktop and mobile navigation
* Mobile menu
* Large hero section
* Oversized responsive typography
* Strong border-based visual hierarchy
* Hard-edged cards and sections
* Primary and secondary CTA buttons
* Light Mode
* Dark Mode
* Theme toggle
* Persistent theme preference
* Responsive layout
* Keyboard-accessible controls
* Visible focus states
* Mobile-friendly design
* Vanilla JavaScript interactions
* No framework dependency
* No backend dependency
* No build tools required

## Design Style

Template 5 follows a bold **Brutalist web design** direction.

Its visual identity includes:

* Oversized typography
* Strong borders
* Sharp rectangular elements
* High visual contrast
* Raw interface styling
* Bold CTA elements
* Distinctive grid layouts
* Minimal decorative elements
* Direct content presentation
* Unconventional spacing

The design intentionally stands apart from traditional SaaS, corporate, and minimal landing pages.

## Light & Dark Mode

The template includes complete Light Mode and Dark Mode support.

Users can switch between themes using the built-in theme toggle.

The selected preference is stored using browser localStorage so the chosen theme can remain active after refreshing the page.

Both themes preserve the original Brutalist visual identity while maintaining readability and contrast.

## Responsive Navbar

The navigation system automatically adapts to different screen sizes.

Desktop layouts display the full navigation interface, while smaller devices use a responsive mobile navigation system.

The navbar includes:

* Brand area
* Navigation links
* Theme toggle
* Mobile menu
* Responsive behavior
* Hover states
* Focus states
* Keyboard-friendly controls
